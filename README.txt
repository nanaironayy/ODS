ARQUIVO SEPARADO EM HTML, CSS E JAVASCRIPT

Arquivos:
- index.html: estrutura principal
- style.css: importa as folhas de estilo originais
- script.js: reúne os scripts inline originais

IMPORTANTE:
O HTML enviado é um export do Canva que carrega a aplicação por meio da pasta
_assets e de um embed remoto. A pasta _assets não veio junto no upload.
Para a página funcionar como no original, mantenha/recupere essa pasta no mesmo
diretório de index.html. A separação dos arquivos não recria o código-fonte
interno do embed remoto.
